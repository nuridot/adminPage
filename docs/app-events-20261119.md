# 앱 이벤트 대시보드 연동

2026-11-18 운영 반영된 API 명세를 기준으로 다음 조회를 연결했다.

| 화면 | API |
| --- | --- |
| 종합 / 사용 | `/api/admin/insights/work-funnel` |
| 사용 | `/api/admin/insights/app-reliability` |
| AI 품질 | `/api/admin/insights/revision-rate` |
| 유지 / 작업 시간 | `/api/admin/insights/activity-time`, `/api/admin/insights/org-retention` |

다섯 API에는 기간, 기관, 앱 버전만 전달한다. 쪽 유형은 기존 AI API에만, 앱 버전은 신규 이벤트 API에만 적용한다. 각 카드에는 서버가 반환한 집계 기준과 수집 시작 시각을 표시한다.

- 수집 기록이 없으면 수치를 숨긴다. 수집된 0건과 분모 없는 비율을 구분한다.
- 실패율에서 취소를, 복구율에서 관찰 중인 미복구를 제외한 서버 비율을 사용한다.
- AI 원문과 엔진 점자 교정을 별도로 표시하고 전체 / 완료 회차를 전환한다. 순 편집률은 100%를 넘을 수 있다.
- 부분 수집은 관측된 활동 합계만 표시한다. 서버 변환 시간과 시작~완료 경과 시간은 별도 지표다.
- 미완료 주의 활동 기관은 현재까지 값으로 표시하고, 유지율 미집계는 0%로 표시하지 않는다.

수집 스위치는 변경하지 않았다. 앱 이벤트가 실제로 수신된 뒤 운영 수치가 나타난다.

검증: `npm run check` — 타입 검사, 55개 테스트, 운영 빌드 통과.
